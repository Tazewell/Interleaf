# BabelDOC 原版式开发计划

- 在 `translation` 分支从 `503cd7d` 开发。用户从阅读器显式选择 BabelDOC 后，复用现有原版式任务的接受、轮询、取消、去重和缓存发布。旧请求和缓存继续有效。
- 用同操作系统的 `pdf2zh_next` CLI 调用 BabelDOC。任务固定使用纸间选定的 OpenAI 兼容翻译模型，密钥经子进程环境传递。CLI 独立配置、任务独立工作目录、用户原件只读。生成英译简中 mono，双栏由现有阅读器组装。
- 缓存标识绑定原文哈希、CLI 修订和影响输出的模型配置。校验 PDF 有效性、逐页尺寸及页数。只有验证过的成品和清单可原子发布，没有已校验的段落对应时不给出虚构映射。
- 先测试 CLI 输出与取消边界、PDF 几何和任务生命周期，再接入 UI 与 OpenAPI。使用本机测试模型响应验证真实引擎，编译并运行全套检查，复查改动后提交本地分支。
