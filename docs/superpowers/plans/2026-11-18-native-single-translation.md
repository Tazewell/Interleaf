## 真实论文

在 Windows 的独立预览书库中，用一篇已有译文的 16 页 SERL 论文测试。单栏的 16 页均为 612 × 792 pt，原版式对照为 1236 × 792 pt。Poppler 在 72 DPI 下逐页比较，单栏与双栏右侧在 7,755,264 个像素上完全一致。

| 检查 | 本次结果 |
| --- | --- |
| 单栏首次排版 | 16.203 秒 |
| 再次请求单栏缓存 | 32 毫秒 |
| 首次请求已有双栏缓存 | 47 毫秒 |
| 缓存文件大小 | 单栏 12,661,539 字节，双栏 16,965,825 字节，减少 25.37% |
| 文本和图形 | 110 段译文写入文本层，73 段保留原文。第 4 页整页保留 |
| 数据与网络 | 原 PDF、版面清单、存储译文与用量记录的摘要一致，生成期间记录到 0 次对外请求 |

两种版式的译页文本层逐页一致。第 10 页有 6 处中点在 PDF 文本层映射成项目符号，包含这些字符的整段精确检索受影响。缓存请求耗时仅衡量本机服务返回缓存的时间。

人工体验时，打开 SERL，依次选择「原版式 → 译文」「原版式 → 对照」。滚到中间页后，将排版切成「流式」并切回，检查当前页、段落位置和工具栏在双侧边栏打开时的排列。
