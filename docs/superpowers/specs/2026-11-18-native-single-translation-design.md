# PDF 阅读内容与排版

阅读工具栏将「看哪部分内容」和「如何排版」放在两个相邻的控件中。初次打开论文时显示原文，排版默认为原版式。读者可以先选排版，也可以在读译文时换排版。

| 阅读内容 | 原版式 | 流式 |
| --- | --- | --- |
| 原文 | 原 PDF | 原 PDF，记录排版选择供查看译文时使用 |
| 对照 | 原 PDF 和原版译页分栏，拖动中线调宽，点 ⇄ 换边，两栏按页内位置同步滚动 | 原 PDF 与流式译文双栏，可单独滚动 |
| 译文 | 每一页显示一张与原页等大的译页 | 连续排列的单栏译文 |

「单栏」指阅读区里只有译页。论文原有的双栏正文、图片和公式仍按原页布局呈现。「原文／对照／译文」使用阅读器已有的滑动分段控件。带图标的排版菜单支持键盘操作，窄阅读区会把翻译操作放到下一行。

## 本地生成

原版式对照和单栏译文共用按原文、版面、已完成译文及渲染器版本生成的 `translation-only` 阅读文件。每一张译页与源页等大。进入对照时，阅读器在相邻窗格打开原 PDF。两栏宽度不同时，跟随栏对齐主动栏视口中心所在的页与页内位置。换边以及切到单栏再返回时保留栏宽和顺序。

单栏合成复用双栏译页的字体、段落适配、图像和公式处理。需要整页保留原样时才嵌入完整源页。无法安全覆盖的段落保留原文，阅读器显示段落数量并提供对应的流式入口。

## 阅读位置、搜索与批注

切换版式时记录原页页码及页内位置。双栏独立滚动时使用最后主动阅读的一侧。段落菜单的「进入双栏对照」沿用当前排版，并定位到选中的段落。译文在后台更新导致 PDF 重新生成时，阅读器会在旧页面卸载前保存视口。

单栏搜索使用当前译页的文本层。聊天引用需要查找原文摘录时使用源 PDF，跳转后可以回到先前的页内位置。只有经段落身份、来源哈希及文字校验的译文选区才会保存为译文批注。原文批注与链接留在对应的原文页面。
