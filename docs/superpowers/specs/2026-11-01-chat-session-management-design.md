# 文档会话管理

用户要求右侧对话栏支持逐个管理、删除会话。继续在已有 dev worktree 开发，不合并 main、不推送、不发布。

## 交互与实现选择

- 保留当前会话选择器与新建入口，添加“会话管理”按钮。管理窗口列出本篇文档的所有会话，每行支持切换、重命名、删除。
- 删除前确认目标会话名称，说明将删除其聊天历史与未发送草稿，保留文档、笔记、批注。删除请求失败时保留会话和确认窗口，允许重试。
- 正在生成回答的会话先停止再删除：前端说明原因，服务端在同一 chatMu 保护区内检查活动运行、运行预留和持久化运行状态，返回 409。
- 删除当前会话后切换到剩余会话；删除最后一个时，在事务中建立新的空白默认会话。删除非当前会话保留当前选择和草稿。
- 后端事务删除目标会话的消息、持久化运行、对应模型续聊状态和已关联的回答审计记录；仅清除批注中指向这些消息的 answerId，保留其正文和其他字段。返回解除关联的批注 ID 与可选替代默认会话。
- 成功后释放该会话的内存 ChatSession、草稿缓存和当前选择记录。已发出的旧列表响应不得复活已删除的会话；未完成的旧文档请求不得改变新文档界面。
- 使用既有 Base UI Dialog/AlertDialog、Button、Select 与图标；不引入依赖或全局样式变化。

## 验证与预览

覆盖跨文档隔离、事务回滚、运行中/预留中拒绝删除、最后会话重建、批注关联解除、取消与失败重试、陈旧异步结果和其他草稿保留。全部真实模型请求使用测试替身；不删除用户测试书库中的会话。运行类型检查、Go/Vitest 测试与构建，更新拥有的本地预览服务并提供手动检查入口；不进行浏览器自动化验收。
