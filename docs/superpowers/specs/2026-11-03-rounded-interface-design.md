# 纸间圆润界面落地

用户已确认阅读页“嵌入式工具栏”、书库主页及导入/设置交互草图，并授权修改代码。参考稿保存在本线程可视化目录的 `interleaf-rounded-sketch.html` 和 `interleaf-library-sketch.html`。保留真实功能、数据和既有存储/API，草图中的示例服务商响应、文件、摘要、页面导航与反馈不能进入产品代码。

## 已确认的界面

- 统一中性背景、浅色面板、柔和边界与 12–24px 圆角；墨绿色集中用于主要操作、来源链接和焦点。沿用现有字体与 Phosphor 图标体系，兼容浅色、深色、纸张和系统外观。
- 书库保留左侧状态/分类、中间论文列表/表格、右侧详情及拖动宽度、批量操作、筛选、研究等入口。顶部论文库/图书库改为滑动分段控件；搜索、列表选中、元信息及详情分组与草图一致。详情采用概览/信息页签，保留所有编辑、引用键、批注和关联论文功能。
- 阅读页使用嵌入式原页/对照/译文分段控件；可点击、键盘操作和拖动吸附。拖动时只移动选中背景，松手后提交离散模式；快速切换、取消拖动、禁用项、尺寸变化和减少动画不能影响状态正确性或阅读位置。
- 右侧对话保留会话管理、真实生成/思考/工具状态、来源定位、重新生成、图片预览及附件发送后清空。优化文字层级、附件卡与圆润紧凑输入区；不添加虚构进度或以示例回答替换内容。
- 导入采用链接、本地文件、文献库迁移、BibTeX 分段入口。使用现有实际下载、原生多文件导入、Zotero/EndNote 迁移和 BibTeX 预览/新建/合并/跳过逻辑，保留分类继承、错误恢复、忙碌保护和引用键变更确认。
- 设置保留 AI、显示、阅读、快捷键、诊断、论文库六类，使用左侧导航和右侧圆润内容面板。AI 连接/模型/翻译提示分组，保留服务商预设、自定义、API Key 编辑语义、模型下拉刷新和检测；主题使用滑动分段，现有开关、滑块、数值范围、日志、代理、存储和期刊指标功能保持可用。

## 实施边界

只在既有 `Interleaf-dev` worktree 的 dev 分支开发；不合并、推送或发布。使用现有 Base UI/shadcn 原语，不安装依赖，不重写后端，不修改用户书库/真实 API 配置。保留 macOS 原生交通灯、标题栏拖动区及 Windows 桌面行为。

宽窗口保留多栏，窄窗口控件换行、面板可滚动且关键入口可到达。键盘焦点明确，正文与次要文字具有可读对比度；交互支持减少动画。验证采用类型检查、适当行为回归、全量测试和构建；遵守仓库要求，不使用浏览器自动化进行视觉验收，交付可访问的本地预览及人工检查步骤。
