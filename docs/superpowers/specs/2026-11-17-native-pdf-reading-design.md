# 原版式 PDF 对照阅读

用户在核对 Zotero PDF2zh 的实现后，明确要求按同一方案修改。当前 dev 已快进到 main 8659bb9，继续在独立 Interleaf-dev 工作，不合并、推送或发版。

目标：同一宽页左原文、右译文，由一个 PDF.js 视口滚动/缩放，消除两个容器追赶；保留当前原页、HTML 译文和流式对照。沿用既有 UI、翻译服务及书库身份。

复用本项目的 native bilingual PDF 生成器，不引入 Python/外部翻译引擎。阅读请求只使用严格匹配的当前可见已存译文，不解析 API 配置、不调用翻译模型、不改变译文、原文件或文献附件。无法安全复用及排版溢出的段落保留原图，报告真实计数并在界面明确显示；不能把原文伪装成译文。没有任何可复用译文时给出恢复提示，仍可切回原页/HTML。

输出按原文、完整解析文件、当前可见译文和渲染器版本构造缓存键；任务取消/失败不发布半成品；缓存重启后可复用，源变化时失效。并发同键去重，删除/关闭取消并等待任务。阅读缓存不占用导出任务名额，不创建附件。

宽页保持原页编号、高度和原页尺寸元数据，页宽为 2*w+12pt。任何保存的阅读位置、AI 页码和原文批注都使用原文坐标。译文选区仅在能精确关联现有 block/sourceHash/target 时形成既有 TranslationLocation；不能把右半页的坐标写成原文高亮。跨侧或无法确认归属的选区可引用页码和真实文本，不能错误保存精确批注。

阅读 UI 保持项目现有分段控件，提供原页、对照（新原版式）、流式对照、译文。新对照显示生成进度、失败重试/返回、原文保留段数；重复打开直接加载缓存。载入缓存或切换视图时保留原页位置。取消或换文档不能让旧请求覆盖新视图。

验收：已有生成器与导出测试保持通过；真实宽页/缺失段落测试；缓存、身份失效、取消/删除、零 API 调用；坐标往返、中文选区/批注及来源跳转；界面模式切换和旧结果隔离。完整 typecheck/test/build 及独立代码审查，提供手动阅读预览。测试不宣称实际 FPS，性能需人工真实滚动验证。

实现决定：首版保守保留无法安全重用的原段落，并明确提示；不静默重译。真实论文验证补充：阅读准备阶段遇到已知的公式字形、文字归属或安全擦除证明失败，保守保留该页原样并提示；仅在原始文字与版面段落的归属可证明时记录保留段落，否则只记录整页提示，不编造段数或选区。清单、身份、页数、区域及图题等结构错误仍中止生成；默认严格导出行为不变。缓存不自动清理正在引用的旧修订。现有应用视觉优先于设计 skill 的通用装饰或品牌建议。

## 已验证行为与限制

已在真实 SERL 论文的独立书库副本完成 16 页生成：110 段使用严格匹配的已存译文，73 个可确认段落保留原样。生成状态实际经历排版及合成逐页进度，缓存重开返回 ready。浏览器数值检查确认只有一个 PDFViewer、16 个宽页且未挂载 HTML 译文；第 7 页切回原页再返回对照仍保持第 7 页，页内位置另有回归测试。原 PDF、版面清单与已存译文未变化，未调用翻译 API。此结果不代表所有论文都能完成原版式排版，也不宣称特定 FPS。

首版仍有边界：历史 HTML 译文批注在宽页右侧按已验证段落显示范围，保存的精确译文锚点不变；原 PDF 内 XYZ/Fit 链接保持目标页，但不完整复现目标缩放和点位。没有可安全复用译文时显示恢复提示；公式、Markdown、缺译或容纳失败的内容保留原图，可使用流式对照。首次生成及任务轮询仍有原文修订校验的 I/O 成本。

最终冻结验证包含 932 个源文件：`pnpm typecheck`、`pnpm test --maxWorkers=4`、`pnpm build` 在隔离 WSL 环境通过，Go 六个测试包通过，Vitest 1,487 项通过、6 项条件跳过。Windows 构建、处理器与阅读专项通过；额外 Windows 全量 Go 检查存在基线也可复现的权限、解析程序环境失败及间歇性诊断计数失败，不归为本次已修复内容。整分支及修复复审无剩余 P1/P2。

人工验收时打开已有译文的 PDF，选择“对照”，分别从左、右内容区域滚动并缩放；核对目录、搜索和页码跳转，再切换原页、流式对照与译文检查位置。遇到原文保留提示时展开排版提示，并在流式对照中查看原有完整译文。
