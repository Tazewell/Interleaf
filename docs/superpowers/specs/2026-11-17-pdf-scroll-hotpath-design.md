# PDF 滚动热点优化

用户已在聊天批准按前轮源码调查继续优化，限定 dev，重点解决实际滚动卡顿。沿用独立 Interleaf-dev 工作目录，基线 f99f2f5，不合并、推送或发版。

上一轮明亮原版式对照采样显示明显样式重算，热点经过 PDF.js 文字层、可见页计算和本项目 onScroll → clearSelection。单视口已解决同步结构，当前任务检查外围滚动工作，不更换语言、引擎或降低清晰度。

滚动条显示状态在每个滚动周期仅切换一次，不重复写同值属性或重建逐帧计时器；避免继承样式变更扩大到 PDF 文字层。维持当前显示/隐藏时机、各主题颜色、跨窗口元素兼容和卸载清理。

PDF 普通滚动在没有本阅读器选区、批注弹窗和 hover 状态时走空闲快速路径，不强制读取全局 Selection 或扫描全部批注。真实选区滚动后仍清除，外部输入和其他阅读器的选区保留；拖选未松手、Escape、点击标注及页面跳转不能回归。未使用 readingAnchor 的视图不执行段落位置扫描；流式对照的真实消费者继续接收锚点，显式 goTo/focus 不受影响。

按相同 PDF、模式、视口和采样方式比较优化前后。观察样式重算、任务时间及调用路径，带采样开销的结果不宣称真实 FPS。只保留有证据或明确减少无效工作的局部修改；若仍卡顿，继续定位文字层和滚动条失效，不盲目增大画布缓存或引入整套 Zotero fork。

采样追加：侧栏圆角的祖先 `:has()` 规则会被 PDF 内部文字层、悬浮工具条增删触发，导致整棵阅读子树样式重算。改为复用现有 React 侧栏状态在阅读区域表达开关，保留原有圆角、边框、工具栏与拖缩开关语义；不禁用 PDF.js 原生选区渲染。

不调用模型、不改原文件/译文/密钥/书库身份。现有用户操作和主题外观保持一致。单元回归、独立审查和 typecheck/test/build 均通过后整理为小提交，提供人工滚动预览；Windows 全量测试的已确认基线环境失败单独披露。

## 实测与验证

本轮不更换 PDF.js、不改变画布像素上限、不禁用原生选区绘制。滚动条针对已有隐藏原生滚动条的 PDF 宿主跳过状态；其他滚动容器仅在周期开始/结束改变显示属性。选区/批注和可选锚点的空闲工作按实际状态跳过。侧栏圆角使用 Workspace 既有 right 状态，不再用祖先 `:has()` 判断 PDF 后代。

真实浏览器数值采样使用已有译文的 SERL：16 个宽页、一个 PDFViewer、明亮主题、视口 1221×763、DPR 1.5。预热后在第 3 页附近向下滚动两次、向上两次，结束位置差约 1.3 CSS 像素。

| 阶段                           | 样式重算累计 | 主线程任务累计 |
| ------------------------------ | -----------: | -------------: |
| 修改前                         |     4.336 秒 |       6.951 秒 |
| 滚动条和空闲交互优化后         |     2.087 秒 |       3.582 秒 |
| 最终侧栏选择器优化，完整刷新后 |     0.054 秒 |       0.668 秒 |

前两项优化后的连续复测样式重算 2.063 秒。invalidation trace 记录到 PDF 内部节点增删使祖先 `:has()` 失效，一次重算覆盖 20,029 个元素。CSS 热更新后仍可观察到此前的失效状态；完整刷新后 offsetLeft/getSelection 热点明显下降，预览测试需先刷新页面。

这些是带开发工具开销的诊断样本。基线采集窗口约 68 秒，中间样本约 23 秒，含不同空闲间隔；最终完整刷新重建文字层，缓存、采样与后台负载也可能不同。不能据此计算严格速度倍数或 FPS，不能代表所有文档、设备、夜间模式与连续触控板滚动。实际手感仍需人工验收。额外的最终 invalidation trace 因工具采集超时未完成，已停止采集，不据此声称没有后续全树重算。

冻结 935 个源文件并逐字节校验；隔离 WSL 的 `pnpm typecheck`、`pnpm test --maxWorkers=4`、`pnpm build` 全部通过：Go 6 个包通过，Vitest 1,509 项通过、6 项条件跳过。Windows 38 个阅读专项文件、320 项测试及前端 build 通过。产品代码提交后再次确认与快照一致；本节及计划交付记录在检查后补充。独立分项及整体审查无剩余 P1/P2。Windows 全量 Go 的既有环境问题沿用前轮记录，本轮没有声称修复。

人工预览：刷新开发地址，打开 SERL，选择“对照”，从左右内容区域各连续滚动并反向滚动；开关右侧栏后重复，再试原页和流式对照。检查文字拖选后滚动、Escape、批注点击与页码跳转。开发改动仅保存在 dev。
