# 流式 PDF 对照滚动优化

承接用户要求在 dev 优化实际双栏滚动，基线 1678197，沿用已隔离的 Interleaf-dev。上一轮实测对应原版式对照，不能把其结果套用到流式对照。

源码确认三项无效工作：原文 anchor 每帧读取所有含段落的页面几何；译文拥有输入权时，原文反向回调的守卫晚于几何扫描；hover/focus 状态变更使整份译文 JSX 重建，非 memo TranslationText 连带重复公式验证。重复同值 hover 可能被 React 跳过，不声称每个 scroll 必然重绘全部内容。

在现有垂直连续 PDF 布局下二分定位可见页，只扫描可见段落及现有相邻间隙。读取当前页几何，避免跨 zoom/resize 缓存过期。保留双栏、栏位偏好、跨页间隙、缺失页面/空白页、源数组更新语义。把同步所有权守卫提前到可选锚点消费者，仍保留显式导航和后续 owner 切换。

hover/focus 使用局部标记更新或稳定内容组件，避免未变内容重算；译文/标注/公式/处理状态更新和所有点击、键盘、重试、引文事件继续生效。不改变画质、原生选区、存储格式、原文/译文/密钥，不调用翻译模型。

以有实际交互的回归证明长文布局读取上界、反向扫描零次和 hover/focus 内容重算零次，覆盖输入接管、取消同步、换模式/文档、卸载、缺页与跨页间隙。完整 typecheck/test/build 和独立审查后小提交，保留 dev，不合并/推送/发布。实际触控板帧率和手感未测时必须明确说明，不能用 jsdom 调用次数代替真实浏览器性能。

## 完成与验证

`fe8fd30` 按当前几何二分连续垂直布局中的可见页；缺失/零尺寸探针回退完整扫描，不缓存跨帧 DOMRect。1000 页/20000 段落回归，旧代码单次 1000 次页面几何读取；新代码首屏、深页 scroll→rAF、混合页高、缩放/窗口变化各不超过 24 次。七页可见的 viewport 不超过 21 次。缺页回退仍允许 O(P)，正确性优先。

`b2f523a` 将 hover/focus 改为已有节点索引上的局部属性标记，包括 aria-current。悬停与焦点真实事件回归中，旧代码产生 15 次 Markdown 组件重绘；新代码不变内容重绘、真实 KaTeX 验证和标注派生均为零。真实译文/公式推送、标注哈希、processing 更新、重试与引文处理仍有回归覆盖。所有权/模式/选区/显式聚焦守卫提前到动态 readingAnchor getter；排队帧与旧文档回调在取消/切换/卸载后失效。

两个任务均先 RED 后 GREEN；分项及整体独立审查无剩余缺陷。冻结 937 个源文件，在隔离 WSL 逐字节核对后运行 typecheck、完整 test、build，全部退出 0：Go 六个包通过，Vitest 1525 通过、6 项条件跳过。Windows 阅读专项 40 文件/400 项通过，前端构建通过。产品提交后再次核对与快照完全一致，本节是检查后的文档补充。构建/测试保留前轮已有的第三方、Canvas 环境和 chunk 大小警告；不声称修复 Windows 全量 Go 的既有环境问题。

本轮没有实际触控板 FPS 或浏览器滚动耗时采样；调用次数只证明指定路径工作量减少，不证明用户卡顿完全消失。完整刷新已有认证预览，打开 SERL 选择“流式对照”，分别滚动原文/译文，快速反向和交换两栏，检查同步开关、段落聚焦、选择和批注。不要用上一轮原版式对照的毫秒数据评价流式模式。
