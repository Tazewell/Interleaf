# 文献库与 LaTeX 引用

论文库按文献显示，每篇文献可以没有附件，也可以包含多份 PDF / EPUB。标题、作者、出版信息、标签、文件夹、星标和引用键属于文献；阅读进度、批注、笔记、对话和翻译属于各自的附件。

## 导入和整理

1. 按现有入口导入 PDF，或在论文库点击「导入 .bib」。`.bib` 可以选择文件，也可以粘贴内容。
2. 点击「预览导入」，核对标题、导入键、匹配条目、未知字段提示和语法错误。
3. 每条记录明确选择「新建」「合并」或「跳过」。合并时选择目标文献；默认保留目标已有键。需要改键时填写替换值，并确认对已有 LaTeX 引用的影响。
4. 预览没有语法错误且每条已有选择后，点击「确认导入」。无 PDF 的记录也会显示在论文库，可编辑信息、分类、加标签、星标、引用和移到回收站。

冲突没有解决时，服务器拒绝整个导入，不写入部分记录。手动修改的字段受保护。Interleaf 保留未映射的 BibTeX 字段、花括号、宏和值拼接，并在导出选集时带上必要的 `crossref` 依赖；依赖缺失会报错。导入内容作为数据处理，不执行 TeX 命令，也不会打开其中的文件或网址。

## 附件与阅读记录

在论文详情的「附件」区域打开指定文件，设置原文、译文、补充材料或其他角色，或点击「设为默认」。列表显示默认附件的阅读进度和全部附件的批注数量汇总。

有批注的附件可点击「查看批注」，再点具体批注，直接定位到该附件的原位置。论文笔记和对话仍在各自附件的阅读界面中。无附件文献不提供阅读、翻译、文件导出或文件信息查找操作。

补入新文件时，先把 PDF / EPUB 导入图书库，再在文献详情选择该文件并点击「添加」。已属于另一篇文献的文件，需要先移出原文献或合并文献。

「移出」只解除附件关系，并把文件放回图书库，保留其阅读记录。文献的「移到回收站」会隐藏整篇文献及所有附件；恢复时一并恢复。永久删除会清理文献及附件的书库副本和阅读数据，请核对确认对话框。导入前的外部原文件不受影响。

## 合并文献

在疑似重复视图或选中多篇文献后打开合并对话框。选择保留的目标条目，并逐项核对冲突字段的保留值。合并保留所有附件及每个文件的阅读数据，缺少的信息补齐，文件夹、标签与星标合并。

若已有不同引用键，必须明确选择保留的键。对话框列出不再导出的旧键和受影响的自动导出文件；确认后才能合并。字段选择、附件移动和引用键选择在同一个事务中提交，验证失败时整体回滚。旧键不生成别名，已有 `.tex` 中的引用需要手动修改。

## 复制与导出引用

详情和右键引用菜单均可「复制引用键」或「复制 LaTeX 引用」。首次复制或导出时分配持久键；以后修改标题、作者、年份、排序或附件不会自动改键。缺作者或年份的文献会提示信息不完整，可先使用稳定备用键，再补充元数据。

「导出引用…」支持 BibTeX、BibLaTeX、RIS、CSL-JSON 和格式化文本。BibTeX / BibLaTeX 的复制、单次导出与自动导出使用同一套服务器序列化规则。导出失败时显示错误，不把错误文本保存成 `.bib`。

手动改键在详情「引用键 → 修改」中进行。确认框展示原键及受影响的自动导出文件；Interleaf 不修改 `.tex` 文件。已有 `.bib` 建议先导入并核对原键，再建立自动导出。

## 文件夹与本地自动导出

把写作项目所需的文献放入一个论文文件夹，然后点击顶部「参考文献…」。选择 BibTeX / BibLaTeX；默认包含子文件夹，可以关闭。模式按文件夹记住。「保存 .bib」生成可上传的文件，浏览器版通过下载保存。

桌面版还提供「设置自动导出位置」，通过原生文件选择器指定本地 `.bib`。已有文件需要选择其他位置，或明确同意备份后接管。网页不能直接注册任意文件路径。

Interleaf 运行时更新已授权的文件，关闭后不更新；下次启动会核对并补导出。列表显示目标路径、最近成功时间、暂停状态和错误，可以「立即更新」或「停止管理（保留文件）」。全部文献的「参考文献…」也可以查看现有目标。

文件夹改名后目标跟随；删除文件夹会暂停目标，保留最后成功的 `.bib`。成员移出导致空文件夹时，仍更新其导出。路径不可用、写入失败或外部修改目标时，不覆盖最后成功的文件。处理外部编辑冲突时，先保留自己的改动，再重新选择位置或明确备份接管。

路径属于运行 Interleaf 的操作系统。WSL 桌面版使用 Linux 路径，Windows 的 `D:\project\refs.bib` 对应 `/mnt/d/project/refs.bib`。

## 上传到 Overleaf

本地自动导出不会自动上传到 Overleaf。手动打开自己的 Overleaf 项目，上传生成的 `references.bib`；后续文献信息变化后重新上传同名文件。没有登录或自动控制 Overleaf 的流程。

复制实际引用键，替换下面示例中的 `YourSavedKey`。现有项目使用哪一种参考文献方案，就选对应导出模式。

BibTeX 示例：

```tex
\documentclass{article}
\begin{document}
Example citation: \cite{YourSavedKey}.
\bibliographystyle{plain}
\bibliography{references}
\end{document}
```

本地编译顺序为 `pdflatex main`、`bibtex main`、`pdflatex main` 两次。

BibLaTeX 示例：

```tex
\documentclass{article}
\usepackage[backend=biber]{biblatex}
\addbibresource{references.bib}
\begin{document}
Example citation: \cite{YourSavedKey}.
\printbibliography
\end{document}
```

本地编译顺序为 `pdflatex main`、`biber main`、`pdflatex main` 两次。包含宏、机构作者和 `crossref` 的真实导出已通过上述两种本地编译流程；Overleaf 云端上传与编译需用户在自己的项目中手动验证。中文文献还需项目已配置合适的中文字体与编译方案。

## 人工验收步骤

- 在临时书库导入一份 PDF 和一份无附件 `.bib` 记录，确认各文献只出现一行；编辑无附件记录的标题、标签和文件夹。
- 为同一文献加入第二份文件，设置译文角色和默认附件，分别打开；在次附件「查看批注」中打开原有批注，确认位置与笔记未串到主附件。
- 导出单篇、改变排序后再导出多篇，确认同一文献的键一致；复制 `\cite{...}` 并与导出文件核对。
- 合并两篇有不同键的文献，检查冲突字段、保留键、旧键和导出影响；未确认前按钮不可提交，合并后所有文件仍可读。
- 区分测试移出附件、文献回收、撤销、恢复和永久删除，仅对临时书库做删除测试。
- 桌面设置文件夹自动导出，修改标题和文件夹成员，再查看成功时间和文件内容；外部编辑 `.bib` 后检查错误提示与文件保留。浏览器仅验证下载入口。
- 手动上传 `.bib` 到 Overleaf，粘贴实际引用键并编译；更新条目后重新上传，核对引用仍有效。
