# 文件夹主题研究

从论文文件夹进入研究，建立独立会话，选择综述、对比或研究想法。主题绑定文件夹身份，是否包含子文件夹由范围设置控制。一次运行冻结活动文献快照：同一论文的原文与译文附件只计一篇，默认读取原文；回收站和范围外文献不参与。没有全文的文献明确标为摘要、仅元数据或不可用。

## 范围、预算与恢复

研究按全范围分批建立证据卡，不只选前几篇。覆盖记录区分论文数量、已读原生单元和未读内容；读取了一页不代表验证整篇论文。模型调用、搜索、远程补读和时间预算独立累计。预算耗尽会暂停，继续时复用仍有效的成功单元；仅元数据记录可能不消耗模型调用。

关闭窗口再打开可恢复任务状态、结果和报告。取消、来源改动或删除会使旧单元失效，已保存历史报告仍可阅读并标记过期。改回旧元数据不会复活已失效的证据；必要时重新下载、重新计费并产生新的来源记录。更新资料后应创建新研究或按界面提示继续，不要把旧报告视为当前来源已验证。

## 联网与明确导入

默认只使用本地资料。明确允许本次任务联网后，Interleaf 向 arXiv、Crossref 发送必要公共学术关键词；这会暴露研究主题。模型接收的原文与公开搜索关键词是不同的数据流。公开资料读取拒绝私网目标、凭据和不安全重定向，不向论文站点转发模型 Key。

检索结果保留来源、时间、DOI/arXiv 等身份；同名论文不因此合并，预印本和正式发表版可按稳定标识关联。一次查新查询的结果数量有界，并非穷尽数据库。限流和网络失败会留下记录，不能解释成“没有相似工作”。成功搜索的检查点在同次继续时可复用；新的研究会重新检索。

搜索与补读不会自动进入书库。点击候选的明确导入才下载并关联本地论文；重试相同请求不产生重复文档。已有有效本地原文优先于远程内容。仅摘要无法验证细节时，结果应保持“证据不足”。

## 阅读、修改和导出

来源面板先校验当前来源，显示标题、引用键或 DOI、位置和摘录。PDF 返回页或图块；EPUB 返回章节与原生定位。已删除、过期或权限失效的来源不再按旧位置跳转。

研究想法列出机制、假设、最近工作、最小实验、基线、消融、证伪条件和资源限制；查新逐项说明重合、差异及未验证部分。“已覆盖”需要相应证据，“证据不足”不等于原创。没有固定创新概率或保证原创的结论，仍需人工阅读和实验。

编辑报告会保存独立用户修订，原生成报告保留；Markdown 导出包含覆盖与来源信息。验收脚本额外生成的 PDF 是实际导出 Markdown 和查新审计的检查样本，不是新增应用内 PDF 报告功能。
