# 内置 AI

Interleaf 的 Go 后端直接连接用户设置的 OpenAI Chat Completions 或 Anthropic Messages 兼容 API，管理原文工具、模型循环、会话和任务。无需安装 Codex、Claude Code、Kimi 或 Pi。普通 `interleaf` 命令行和本地 PDF Node 处理器继续保留。

## 配置与迁移

在设置的 AI 页面保存 API 地址、协议和 Key，再分别选择问答、翻译、图片、研究模型。研究模型留空时继承问答模型；图片用途需要实际视觉能力检测。模型目录可用不等于模型支持工具或图片。能力未知时使用文字辅助，只有主动检测才发送探针。

Key 由本机后端私有配置保存，公开设置响应只返回是否存在，不回传 Key。更换端点需要重新配置密钥；本地文件保护不等于系统密钥链加密。不要分享书库配置或包含鉴权信息的服务启动日志。Interleaf 不读取其他应用的登录凭据。

旧 version 1 配置迁移为 version 2，并保留 `.v1.bak`。原来的提供方归属、历史消息、笔记、批注、译文和引用键仍保留；旧外部线程与 Pi 状态不作为新模型上下文。缺少 API 配置时提示设置，不会静默恢复旧 CLI。迁移前仍建议用户自行备份书库。

## 调用与保存

每次任务冻结地址、模型、Key 和思考配置。编辑设置影响后续任务，不会在一次调用中途更换提供方。文本和图片增量显示；完整提供方结束、工具及来源校验、持久保存全部成功后才确认完成。截断、错误或取消不会把半成品保存为成功，也没有自动备用模型。

订阅断开只停止当前界面接收，不取消已经接受的后台会话；重新打开先恢复状态和历史，不自动重放付费 POST。用户停止、删除、退出和迁移会取消并等待相关工作结束。失败后明确重试使用当前配置，保留此前成功成果。

## 数据外发

使用 AI 时，所需选区、元数据、已读原文、对话和主动选择的图片会发送到配置的模型服务。后台翻译受自动处理设置控制；EPUB 按原生章节定位，PDF 按页和图块定位。模型服务的费用、保存策略与质量由该服务决定。

研究联网另外向公开学术服务发送必要关键词，详见[主题研究](topic-research.md)。模型文字不能替代核对原文；确定性协议验收也不能证明真实科学质量。双语导出步骤见[原生双语 PDF](native-bilingual-pdf.md)，验收与人工检查见[验证说明](native-ai-research-validation.md)。
