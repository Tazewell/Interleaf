# 原生双语 PDF

桌面版可将带横排文字层的 PDF 导出为左右并排或逐页交替的双语 PDF。译文使用随应用打包并嵌入 PDF 的中文字体，可选择、复制和搜索。原文保留矢量内容。

## 配置自己的 API

1. 打开「设置 → Agent 连接」，点击 API 卡片（「配置 API Key」）。
2. 在「API 配置」填写服务商的「API 地址」「API 协议」「API Key」，点击「保存」。协议按服务商接口选择 OpenAI Chat Completions 或 Anthropic Messages。
3. 在模型列表中选择服务商提供的模型；列表未列出时，用「添加模型 ID」手动添加准确的模型 ID。
4. 临时选择 API 为当前 Agent，在「翻译模型」中为 API 选择该模型。配置完成后可切回其他问答 Agent；双语 PDF 导出仍使用已配置的 API 翻译模型。

API 地址、密钥和翻译模型取自现有设置。导出任务创建时冻结配置，修改设置后需要重新创建任务。明确开始翻译才会调用 API，费用由所选服务商收取。

## 导出与取消

1. 导入 PDF，等待文献封面的版面解析阶段结束，打开文档的导出对话框。
2. 在「双语 PDF」区域选择「左右并排」或「逐页交替」，可填写「起始页」「结束页」；留空表示全文。
3. 点击「预检双语 PDF」，查看原文页数、输出页数和缺少译文的段落数。没有安全横排文字的页面，必须明确选择保留原文后才能继续。
4. 确认后点击「翻译并导出」（已有全部译文时为「生成双语 PDF」）。完成后点击「保存双语 PDF」，在系统原生文件选择器中选择位置。
5. 如需归档，勾选「添加为此文献的翻译附件」。只有文件保存成功后才挂入当前文献，重复挂入相同内容会去重；主附件和引用键不变。

任务运行时可点击「取消双语导出」，也可关闭对话框取消。取消系统保存选择器不会添加附件。如果文件已保存但挂附件失败，界面会分别报告结果，并允许重试挂入。

开始响应中断时，界面会查询同一任务；查询也失败时点击「重试查询」继续取回该任务，恢复期间开始按钮禁用，不会自动重新翻译或新建任务。如果查询确认任务仍在等待开始，界面保留原来的错误，可按提示处理后明确重试。任务已完成时可以直接保存。

左右并排将 N 页变为 N 页，每页宽为原页宽度的两倍加 12 pt 间隔，原文在左、译文在右。逐页交替将 N 页变为 2N 页，每个译文页紧接对应原文页，保持该页物理尺寸；混合尺寸原文逐页保留各自大小。

## 当前范围

- 适用于带横排文字层的 PDF；不提供 OCR，竖排或侧向文字不强制翻译。
- 图、表、代码、算法、参考文献及其内部原文保留；可识别的图题、表题和脚注参与翻译。公式以原页图像保留，公式内部文字不可作为新译文搜索。
- 正文最低 9 pt。无法在原区域容纳译文时任务失败，溢出错误给出页码和段落，不裁切译文或静默换回英文。
- 预检依赖已完成的 PDF 版面解析。导出不会写回原文、阅读译文、批注或文献笔记。
